# V2 rechazada por Alain

Los personajes V2 no representan adecuadamente las referencias. No están aprobados para producción, rig ni animación. Las imágenes y modelos se conservan como historial; no deben usarse como base final.

Problemas de construcción identificados: extremidades fuera de la silueta de referencia, separación insuficiente entre piernas, hombros y cuello mal resueltos, rostros simplificados, ropa construida como volúmenes genéricos y detalles que no siguen la superficie. Tener una malla cerrada o un FBX importable no demuestra calidad anatómica ni fidelidad visual.

La corrección comienza con un solo personaje: civil masculino de chaqueta naranja (referencia 01). Se alinearon las tres vistas sobre el mismo suelo y escala. Las guías representan medidas de trabajo tomadas de la imagen; no son un personaje ni un rig final. La lámina puede contener diferencias entre vistas, que se resolverán durante el modelado.

La nueva escena de trabajo se guarda en `Assets/Party/Art/BlenderSources~/NPC01_ReferenceCalibration.blend`. No se exporta este estudio a Unity. El siguiente trabajo pendiente es construir y revisar la anatomía y la ropa de ese personaje frente a las referencias antes de generar variantes.
